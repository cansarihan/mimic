      What is mimic

      Mimic finds the variants of a known bug. It runs a set of structural rules over your Go source, and it ranks the functions that structurally resemble a reference you choose — so a bug fixed in one place leads you to its copy-paste siblings.

      It reads source, not types, so it runs on any Go that parses. The rules need no build.
